# Auric Hardcastle

Based in Singapore. Interested in machine learning, language, and operations research.

### Selected projects

- [LeRobot dataset checks](https://github.com/aurichardcastle/lerobot-dataset-check) — A Python command-line tool for checking the integrity of LeRobot v2.1 datasets.
- [Presupposed vs. asserted falsehoods](https://github.com/aurichardcastle/presupposed-vs-asserted-falsehoods) — Experiments on how question framing affects LLM responses to false premises, with data and analysis code.
- [Jane Street neural network puzzle](https://github.com/aurichardcastle/jane-street-neural-net-solver) — Code for reconstructing a shuffled residual network. Joint work with Keegan Ratner.
- [Sichuan dialect in hip-hop lyrics](https://github.com/aurichardcastle/sichuan-dialect-perception-and-textual-absence) — A coded lyric corpus and interview materials examining dialect in Chengdu hip-hop.
